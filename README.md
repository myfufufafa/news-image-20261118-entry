One image summing up the world news of Wednesday 18 November 2026: a dense
front page — "THE WORLD IN ONE DAY" — with 30 stories from 6 continents and
a small world-map panel marking where each lead story happened.

The image (`entry.png`, 1024×1024, 466,733 bytes) was generated with an AI
image tool from news reported on the day, and checked against several outlets
(Reuters, AP, BBC, CNN, and Indian press summaries of the day's wires).
`main.py` (Python 3.13, standard library only) copies it to the output
directory as `entry.png`.

v2 changes vs v1 (96.4993%, 11–1, rank 1244/2237): the front page now carries
30 stories instead of ~7, adds the world-map panel, fixes the Quad flag panel
(United States, Japan, India and Australia — each shown once; v1 showed India
twice), and cuts the file from 806,951 bytes to 466,733 bytes. The image
generator dropped two brief numbers (22 and 24) from the printed list, so the
page shows 30 stories while its masthead counts 32.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
